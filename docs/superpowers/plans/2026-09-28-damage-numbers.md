# Damage Numbers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** World-space damage numbers in `survivors.html`: a NovelMix digit strip, merging of rapid hits, gold "crit" numbers for combo-boosted hits, red numbers for hits on the player, and a pause-screen toggle to turn them off.

**Architecture:** The pooled numbers live in their own file, `survivor-damage-numbers.js` (`SurvivorDamageNumbers`). `SurvivorJuice` owns them as `this.juice.numbers`. The simulation calls two presentation hooks, `juice.damage(target, amount, boost)` and `juice.hurt(amount)`. Both only read their arguments, and they are no-ops when the juice or the setting is off. `hit()` computes `boost`, the product of the conditional multipliers (relic combo bonuses, owl mark, web vulnerability), as a local variable. The juice decides that `boost >= 1.25` is a crit. The digit strip is generated by `scripts/build-ui-assets.py` and listed in the FX manifest like every other sheet.

**Tech Stack:** Phaser 4.2.1, plain browser JS (IIFE modules on `window`), Python 3 + Pillow for the asset build, Playwright checks (`scripts/check-*.cjs`) run by `node scripts/test-survivors.cjs`.

**Spec:** `docs/superpowers/specs/2026-09-28-reward-juice-design.md` (Phase 3, and the "Damage" row of "Data flow per moment")

## Global Constraints

- Presentation never changes the simulation. Juice code reads game state and never writes to it. Cosmetic randomness uses the juice's own RNG (`juice.rand()`): never `this.rand()`, never `Math.random()`, never `camera.shake()`, and never new `Text` objects from a hook.
- Logic first, animation after. The damage is applied before the number shows it.
- Pauses never stretch time. Nothing in this plan touches `STEP`, `elapsed` or `window.advanceTime`.
- Reduced motion turns off shake, freezes, flashes and the menu pan. Fades stay. For numbers, that means no scale pop and no `Damage_Crit` burst. The rise and fade stay.
- "A number in world space. Hits on the same target within 150ms merge. Crits get `Damage_Crit`. At most 40 on screen." (spec, Data flow)
- Font: NovelMix `font_medium_9px.ttf` at 9px and exact multiples only.
- Every existing `scripts/check-*.cjs` must produce the same numbers. This phase changes no balance.
- **Crit, as decided by the user on 2026-09-28:** a hit is a crit when conditional bonuses raised it by 25% or more. Those bonuses are the relic multipliers inside `relics.modifyHit` (Pack, Resonance, Hunter), the owl mark (×1.25) and web vulnerability. Unconditional multipliers (`partyDamage`, frog `damageMultiplier`) never count.
- Settings persist under `localStorage` key `scrollmonsters-survivor-settings-v1` as `{"damageNumbers": true|false}`, defaulting to on. Every read and write is wrapped in try/catch.
- Never `git add -A`. Stage the named files only. The user has unrelated uncommitted art (`assets/MapAssets/…`, `.DS_Store`).

## Review Focus

1. **Fractional and huge amounts.** Echo hits are 40% of a hit (for example 0.96), and late builds can hit for very large values. Expect at least "1", never "0" or "NaN", and at most 5 digits. Test: Task 2, `fractional and huge`.
2. **Pool exhaustion while merging.** When a target's entry was recycled for another target, a new hit on the first target must start a fresh number, not add to a stranger's. Test: Task 2, `recycle never merges into another target`.
3. **Restart (R) with numbers on screen.** `start()` → `juice.reset()` must hide every number at once. Test: Task 2, `reset clears`.
4. **Storage that throws** (private mode, blocked site data). The toggle must still work for the session, with no page error. Test: Task 4, `storage throws`.
5. **Numbers over the HUD.** Numbers are world objects and must draw under the 2x UI (`ui.root` depth 10000) in portrait and landscape. Test: Task 2, `depth below the UI`.

```python
FONT = ROOT / 'assets/ui/font_medium_9px.ttf'
DIGITS_OUT = ROOT / 'assets/ui/damage_digits.png'
def digit_strip():
    """White NovelMix digits with a 1px dark outline in 8x9 cells, and each digit's advance.

    At 9px the digit glyphs are at most 6px wide and 7px tall and start 4px below the em top,
    so drawing at (1, -3) leaves exactly one outline pixel on every side.
    """
    font = ImageFont.truetype(str(FONT), 9)
    cw, ch = 8, 9
    strip, adv = Image.new('RGBA', (cw * 10, ch), (0, 0, 0, 0)), []
    for d in range(10):
        glyph = Image.new('L', (cw, ch), 0)
        draw = ImageDraw.Draw(glyph); draw.fontmode = '1'
        draw.text((1, -3), str(d), font=font, fill=255)
        box = glyph.getbbox()
        assert box and box[0] >= 1 and box[1] >= 1 and box[2] <= cw - 1 and box[3] <= ch - 1, (d, box)
        cell = Image.new('RGBA', (cw, ch), (0, 0, 0, 0))
        cell.paste((18, 10, 26, 255), (0, 0), glyph.filter(ImageFilter.MaxFilter(3)))
        cell.paste((255, 255, 255, 255), (0, 0), glyph)
        strip.paste(cell, (d * cw, 0))
        adv.append(int(font.getlength(str(d))))
    strip.save(DIGITS_OUT)
    return {'src': 'assets/ui/damage_digits.png', 'fw': cw, 'fh': ch, 'n': 10, 'fps': 1, 'loop': False, 'ax': 0, 'ay': ch // 2, 'adv': adv}
```

- [ ] **Step 3: Create `survivor-damage-numbers.js`**

```js
(() => {
  'use strict';
  const MAX = 40, MERGE_MS = 150, DIGITS = 5, LIFE = 700, CRIT_LIFE = 900, RISE = 18, POP_MS = 120, FADE_MS = 250, DEPTH = 9990;
  const WHITE = 0xffffff, GOLD = 0xffc41b, RED = 0xef5266;
  // World-space damage numbers from the NovelMix digit strip. Presentation only: never writes game state.
  // Every object is made once here (40 numbers x 5 digits) and reused; nothing is created per hit.
  class SurvivorDamageNumbers {
    constructor(juice){
      const s=juice.s;this.j=juice;this.adv=FX_SHEETS.Damage_Digits.adv;this.spawned=0;
      this.pool=Array.from({length:MAX},()=>{const box=s.add.container(0,0).setDepth(DEPTH).setVisible(false);
        const digits=Array.from({length:DIGITS},()=>{const im=s.add.image(0,0,'Damage_Digits',juice.frameName('Damage_Digits',0)).setOrigin(0,.5);box.add(im);return im;});
        return {box,digits,live:false,target:null};});
    }
    reset(){for(const n of this.pool){n.live=false;n.target=null;n.box.setVisible(false);}}
    list(){return this.pool.filter(n=>n.live).map(n=>({value:n.value,crit:n.crit,hurt:n.hurt,x:n.x,y:n.y,scale:n.box.scaleX,depth:n.box.depth}));}
    show(target,amount,{crit=false,hurt=false}={}){
      const now=this.j.now();
      let n=this.pool.find(v=>v.live&&v.target===target&&now-v.last<=MERGE_MS);
      if(n){n.sum+=amount;n.crit||=crit;}
      else{
        n=this.pool.find(v=>!v.live)||this.pool.reduce((a,b)=>a.last<=b.last?a:b); // full: recycle the oldest
        Object.assign(n,{live:true,target,sum:amount,crit,hurt,born:now,x:target.x+(this.j.rand()*2-1)*6,y:target.y-(target.r||10)-6});this.spawned++;
      }
      n.last=now;n.value=Math.min(99999,Math.max(1,Math.round(n.sum)));
      this.layout(n);this.animate(n,now);
      if(crit&&!this.j.reduced)this.j.play('Damage_Crit',n.x,n.y,{scale:2,depth:DEPTH-1});
    }
    layout(n){
      const str=String(n.value),tint=n.hurt?RED:n.crit?GOLD:WHITE;let x=0;
      n.digits.forEach((im,i)=>{const ch=str[i];im.setVisible(ch!==undefined);if(ch===undefined)return;
        im.setFrame(this.j.frameName('Damage_Digits',+ch)).setPosition(x,0).setTint(tint);x+=this.adv[+ch];});
      for(const im of n.digits)im.x-=Math.round(x/2); // centred on the hit
      n.box.setVisible(true);
    }
    // Rise from the first hit, pop and fade from the latest one, so merged hits keep climbing.
    animate(n,now){
      const life=n.crit?CRIT_LIFE:LIFE,since=now-n.last,k=Math.min(1,(now-n.born)/life);
      const pop=this.j.reduced?0:Math.max(0,1-since/POP_MS)*.6;
      n.box.setPosition(n.x,n.y-RISE*(1-Math.pow(1-k,3))).setScale((n.crit?3:2)*(1+pop)).setAlpha(since>life-FADE_MS?Math.max(0,(life-since)/FADE_MS):1);
    }
    update(now){for(const n of this.pool){if(!n.live)continue;if(now-n.last>=(n.crit?CRIT_LIFE:LIFE)){n.live=false;n.target=null;n.box.setVisible(false);}else this.animate(n,now);}}
  }
  window.SurvivorDamageNumbers = SurvivorDamageNumbers;
})();
```
